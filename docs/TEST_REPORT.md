`node --check` для main.js, animations.js и browser_checks.cjs: без ошибок.

## Браузер

[Машиночитаемый результат](browser-results.json), [размеры](viewport-results.json). На `/`, `/portfolio`, `/privacy` проверены 320, 375, 390, 768, 1024, 1440, 1920 px — **21 сочетание без горизонтального переполнения**. На главной дополнительно проверено отсутствие пересечения прямоугольников заголовка и портрета.

Проверены:

- Локальные ссылки и якоря, категории 6/2/1/3 работы, открытие фотографий.
- Стрелки в dialog, Tab внутри, Escape, возврат фокуса к открывшей кнопке.
- Предвыбор услуги и отправка формы, ответ 201 при первой отправке, 200 при повторе; очистка полей после успеха.
- Отдельным SQL-запросом подтверждена ровно одна запись для browser-v2@example.com после повторных прогонов.
- Мобильное меню, переход по пункту и закрытие; синтетический свайп в touch-enabled Chromium.
- Runtime-переключение reduced motion и отсутствие анимации портрета.
- Без JavaScript доступны меню, шесть работ и прямые ссылки на оригиналы; для формы дано пояснение.
- Ошибок JavaScript/консоли и HTTP-ответов >=400 в итоговом сценарии нет.

Сценарий: `scripts/browser_checks.cjs`. Требует Playwright и браузер; backend запускается отдельно с тестовой DATABASE_PATH. Пример Linux: `BROWSER_PATH=/usr/bin/chromium node scripts/browser_checks.cjs`. Он намеренно отказывается работать с нелокальным hostname.

## Визуальная проверка и ограничения

Скриншоты получены из работающих FastAPI-приложений, а не из макетов. `before-*` — исходный HEAD, запущенный отдельно на 4174; остальные — v2 на 4173. Скриншоты секций скрывают только фиксированный индикатор прокрутки и skip-link при захвате, чтобы избежать артефактов Chromium при увеличении области снимка; реальное приложение сохраняет оба элемента. Обложка — HTML-композиция реальных desktop/mobile снимков.

Осмотрены desktop, мобильный экран, laptop 1024, галерея, панорама, биография и контакты. Исходный Netrun URL не открылся (`ERR_TUNNEL_CONNECTION_FAILED`), поэтому сравнение относится к локальному исходному репозиторию. Отдельный первоначальный референс отсутствует.

Не проверены реальные Windows, Safari/Firefox, физические iOS/Android, аппаратный свайп и screen reader. Не проводились нагрузочный тест, проверка действующей конфигурации Netrun и полевой замер Core Web Vitals. Поддерживаемые native page transitions имеют обычную навигацию как fallback. Публикация и миграция рабочей БД не выполнялись.
