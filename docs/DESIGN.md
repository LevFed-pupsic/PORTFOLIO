# MOROZOV v2 — дизайн и движение

Редакционная обложка вместо наложения текста на лицо. Графит `#141512`, бумага `#e5e1d6`, тёплый акцент `#c9ad88`. Системные Georgia и Arial, никаких внешних запросов шрифтов. Разная плотность тёмных и светлых разделов создаёт ритм без декоративных карточек.

## До и после

| До | v2 |
|---|---|
| Жирный заголовок пересекает фото; «Фотограф» закрывает лицо | Две независимые колонки, имя с курсивной второй строкой, подпись над заголовком |
| Минимум 790 px только для hero | Обложка учитывает высоту окна; отдельная настройка для небольшого ноутбука |
| Два повторяющихся столбца галереи | 12-колоночная редакционная сетка: крупный портрет, малая вертикаль, архитектурный разворот |
| Нет полноширинной фотопаузы | Панорамная серия «Последний свет» |
| Коричневая биография | Светлая бумажная композиция с портретом и крупным текстом |
| Одинаковая подача блоков | Нумерованные услуги, контактная композиция, крупный финальный заголовок |

## Движение

- Вступительное появление строк имени: 0,8 с, вторая строка с задержкой 0,12 с.
- Раскрытие портрета через маску: 1,1 с, без заставки и блокировки управления.
- IntersectionObserver запускает мягкое появление разделов и маску фото; до запуска элементы видны, ошибка JS не скрывает страницу.
- При фильтрации фотографии появляются за 0,45 с; скрытые исключены из Tab-порядка. Сетка перестраивается без пустых позиций.
- Hover-увеличение до 1,045 только для точного указателя; подпись всегда видна на мобильном устройстве.
- В dialog — короткое появление кадра, стрелки, Escape, циклический Tab и возврат фокуса; свайпы.
- Параллакс портрета ограничен 10 px, только desktop + fine pointer.
- Индикатор чтения обновляется через requestAnimationFrame, без перехвата прокрутки.
- Native View Transitions для переходов между документами в поддерживающих браузерах; остальные используют обычную навигацию.
- `prefers-reduced-motion` отключает анимации, параллакс и плавную прокрутку, включая изменение настройки во время просмотра.

Кастомный курсор и магнитное движение кнопок не добавлены: у фотогалереи уже есть ясные интерактивные подписи, а постоянное движение ухудшало бы спокойный характер интерфейса.

## Мобильная композиция

Имя над портретом, фото с редакционным отступом слева, CTA под фото. Второй кадр каждой пары смещён вправо. Услуги и контакты идут последовательно. Меню доступно с клавиатуры и без JS; no-JS стили подключаются через noscript, не вызывая скачка страницы при загрузке JS.
