Разработка адаптивного сайта-портфолио фотографа в стиле Cinematic Editorial.

Реализованы индивидуальный дизайн, плавные анимации, интерактивная галерея, мобильная версия, форма обратной связи и сохранение заявок в базе данных.

Технологии: Python, FastAPI, SQLite, HTML, CSS, JavaScript.

Демонстрационный проект.
