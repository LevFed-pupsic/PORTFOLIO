# MOROZOV — Cinematic Photography Portfolio

Полноценный демонстрационный сайт фотографа: FastAPI + Jinja2 + SQLite, HTML/CSS и обычный JavaScript. Фотограф, биография, цены и контакты вымышлены; фотографии предоставлены Unsplash, а не сняты персонажем сайта.

## Что работает

- Главная страница: представление, галерея с фильтрами, биография, услуги и форма.
- Отдельные `/portfolio` и `/privacy`.
- Полноэкранный просмотр в `dialog`, кнопки, стрелки клавиатуры, Escape и свайпы.
- Мобильное меню, мягкие появления, параллакс до 16 px, `prefers-reduced-motion`.
- Серверная валидация, сохранение в SQLite и обработка ошибок.
- Подписанный токен формы, honeypot, задержка 2 секунды, 5 новых заявок за 10 минут с одного адреса подключения, дедупликация одинакового содержимого за 24 часа.
- Локальные WebP, мобильные варианты и lazy loading. Никаких CDN или внешних шрифтов.

## Запуск на Windows

Проверенная серверная среда: Python 3.12 на Linux. Команды ниже предназначены для PowerShell Windows; сама Windows в этой сессии не тестировалась.

1. Распакуйте архив. Откройте терминал **в папке `morozov`**, где лежит `requirements.txt`.
2. Создайте окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. Установите секрет для текущей сессии и запустите приложение:

```powershell
$env:APP_SECRET = .\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_hex(32))"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

4. Откройте http://127.0.0.1:8000 . Остановка сервера: `Ctrl+C`.

Активация окружения не требуется, поэтому менять ExecutionPolicy не нужно. Если Python 3.12 уже выбран по умолчанию, можно заменить `py -3.12` на `python`.

`APP_SECRET` должен оставаться одинаковым между рабочими перезапусками на хостинге; сохраните его в настройках окружения хостинга, не в Git. Если переменная отсутствует, создаётся случайный ключ на время процесса: старые формы после перезапуска перестанут действовать, дедупликация прошлых записей по хешу не сохранится. `.env.example` — пример, автоматическая загрузка `.env` не используется.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты используют отдельную временную базу и не затрагивают рабочие заявки. Фактический результат разработки и ограничения: [docs/TEST_REPORT.md](docs/TEST_REPORT.md).

Для ручной проверки откройте страницу, подождите более 2 секунд, заполните форму тестовыми данными и отправьте. Успешный ответ означает сохранение в БД, **не отправку email**. Уведомления не подключены.

Посмотреть сохранённые заявки можно локально:

```powershell
.\.venv\Scripts\python.exe scripts/read_inquiries.py
```

База создаётся в `var/inquiries.sqlite3`. Она не включена в ZIP и игнорируется Git. Веб-админки и публичного списка заявок нет.

## Где менять содержимое

Основной файл: `app/data/content.json`. После изменения JSON перезапустите сервер (наблюдатель Uvicorn не обязан отслеживать JSON).

| Поле | Что меняет |
|---|---|
| `name`, `brand`, `first_name`, `last_name` | Имя, логотип, заголовок |
| `intro`, `bio`, `experience` | Представление и биография |
| `location`, `email`, `socials` | Контакты и социальные ссылки |
| `hero`, `about_image`, `contact_image` | Фото секций, имя файла без расширения |
| `services` | Идентификаторы услуг, заголовки, описания и цены |
| `works` | Работы, заголовки, категории, годы, alt и фотографии |

Подробная инструкция с примерами и требованиями к фото: [docs/CUSTOMIZATION.md](docs/CUSTOMIZATION.md). Статичные названия разделов и служебные подписи редактируются в шаблонах.

## Размещение на хостинге

Нужен хостинг, который запускает Python/ASGI и предоставляет постоянный локальный диск. GitHub Pages запускает только статические файлы и не подходит для этой серверной формы. Внешняя публикация в ходе разработки не выполнялась.

- Установите `requirements.txt`.
- Укажите `APP_SECRET` как секретную переменную и `DATABASE_PATH` как абсолютный путь к постоянному диску, например `/data/inquiries.sqlite3`.
- Запуск: `python -m uvicorn app.main:app --host 0.0.0.0 --port 8000` (порт согласовать с хостингом).
- Используйте HTTPS, один экземпляр приложения и резервное копирование SQLite. Не храните SQLite на временном диске или общем сетевом томе.
- Если есть reverse proxy, доверяйте forwarded-заголовкам только его известному адресу. Иначе определение IP для лимитов и проверка Origin могут работать неправильно. Не включайте доверие ко всем адресам без проверки схемы развёртывания.
- Замените демоконтакты, ссылки на главные страницы платформ, биографию, цены и текст `/privacy` до коммерческого использования.
- Добавьте абсолютный canonical URL и sitemap после выбора реального домена. OG image формируется из адреса запроса.
- Лимит на Python-уровне — базовая защита формы, не DDoS-защита. Для публичного сайта добавьте ограничения запросов на reverse proxy. Журналы самого хостинга могут сохранять IP.
- Ограничьте доступ к файлу БД системными правами, определите срок хранения заявок и порядок их удаления. Изображения в `static` публичны; ничего приватного туда не кладите.
